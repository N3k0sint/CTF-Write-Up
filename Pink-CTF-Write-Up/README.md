# PINK+ CTF

**PINK+ CTF** is a cybersecurity hacking competition featuring a distinct Bavarian theme ("Servus Hacker!", beer, and pretzels) hosted on a CTFd-powered platform. 

## 🔍 Challenge Categories
Participants can expect to test their skills across several classic and unique challenge domains:
* 🔑 **Crypto** (Cryptography)
* 🖼 **Stegano** (Steganography)
* ⛏ **Minecraft** (Game-based hacking/exploitation)
* 🕵 **OSINT** (Open Source Intelligence)
* 🏔 **Reversing** (Reverse Engineering)
* 🥨 **Misc** (Miscellaneous)
